# Deployment Guide

## Backend Deployment (Railway)
1. Connect your repo to Railway
2. Add PostgreSQL from Neon
3. Set all required environment variables
4. Deploy!

## Frontend Deployment
### Amazon App Store
1. Sign up for Amazon Appstore Developer Account
2. Build APK/ABB
3. Upload to Appstore

### F-Droid
1. Follow F-Droid submission guidelines
2. Ensure all dependencies are open source
3. Submit your app
